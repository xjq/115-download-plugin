115 扫码获取 Token / Cookie

全程在浏览器里完成：向 115 官方接口取二维码 → 手机 115 App 扫码 → 轮询状态 → 换取登录 Cookie。
不经过任何第三方服务器，结果只显示在本页，不写入存储；关掉页面即丢弃。

1获取二维码 Token

点「获取二维码」后，这里显示 115 登录二维码
有效期约 2 分钟，过期需重新获取
尚未获取二维码
uid time sign qrcode

2扫码登录，换取 Cookie

「开始等待扫码」后：二维码被扫 → 手机上确认 → 自动兑换 Cookie。 自检会用 jsQR 解码上面显示的二维码，和 token 里的 uid 比对，确认渲染没出错。

注意：兑换出的 Cookie 会被 115 标成上面选的设备类型，同一类型里已登录的旧设备会被踢下线（例如选「网页版」会让当前电脑的 115 网页登录失效）。 扫码用 115 App 还是微信小程序，都不影响这个设备类型。

Cookie 等价于账号凭据，别贴到公开的地方。本扩展的平时使用 不需要它——在浏览器里登录 115 网页版即可。

· 接口链路（与命令行脚本一致）：
  GET qrcodeapi.115.com/api/1.0/web/1.0/token/ → GET qrcodeapi.115.com/api/1.0/{app}/1.0/qrcode/?uid=…
  GET qrcodeapi.115.com/get/status/?uid&time&sign（status: 0 未扫 / 1 已扫 / 2 已确认 / -1 过期 / -2 取消）
  POST passportapi.115.com/app/1.0/{app}/1.0/login/qrcode/（account=uid）→ set-cookie
· 二维码图片的内容是 https://yun.115.com/scan/dg-<uid>，与 token 里的 qrcode 字段只有域名不同，所以自检只比对 uid。
